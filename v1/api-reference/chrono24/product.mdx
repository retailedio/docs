### Header

<ParamField header="x-api-key" type="string" required={true}>
    Parameter defines the Retailed private key to use.
</ParamField>

### Parameters

<ParamField query="query" type="string" optional={false} placeholder="https://www.chrono24.com/rolex/rolex-submariner-date-41mm-126610ln-unworn-2022--id16516741.htm">
    Chrono24 Product URL
</ParamField>

<ParamField query="shipping_country" type="string" optional={true} placeholder="US">
    Buyer shipping country as an ISO 3166-1 alpha-2 code (e.g., `US`, `FR`, `GB`). Chrono24 includes the import VAT of this country in the listing price, so the same listing can show different prices depending on the buyer's country (e.g., a US seller's `$45,000` listing shows as `$54,000` for a buyer in France, which includes 20% French VAT). Pass `US` to get the price shown to US buyers. If omitted, the country is inferred from the request's IP and the price may vary between calls. The country used is returned in `price.shipping_country`.
</ParamField>
