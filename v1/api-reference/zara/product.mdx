---
title: "Zara Product"

description: "Get product information from Zara"
---

### Header

<ParamField header="x-api-key" type="string" required={true}>
    Parameter defines the Retailed private key to use.
</ParamField>

### Parameters

<ParamField query="query" type="string" optional={false} placeholder="389358438">
    Product Id : `389358438` or Zara URL
</ParamField>

<ParamField query="country" type="string" optional={false} placeholder="FR">
    Country code : `FR` or `US`
</ParamField>
