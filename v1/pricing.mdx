Each Retailed plan provides a monthly allocation of API credits. Making requests to the Retailed API costs between 1 and 2 credits, depending on the endpoint complexity and resource usage.

<Info>
    Most of our endpoints consume 1 credit per request. Premium endpoints that require more processing power or complex data extraction cost 2 credits.
</Info>

## API Credit Costs by Endpoint

| Feature              | Credit Cost | Description |
|---------------------|-------------|-------------|
| StockX endpoints    | 2 | Real-time product data and market analytics |
| Other endpoints     | 1 | Standard data extraction and processing |

## Plans Overview

<Note>
    The free plan includes a limited number of credits per month, perfect for testing and small projects. For production use, we recommend our paid plans for reliable access to larger credit pools.
</Note>


## Getting Started

1. Browse our [pricing page](https://www.retailed.io/datasources/pricing) to compare plans
2. Start with our free tier to test the API
3. Upgrade anytime as your needs grow
